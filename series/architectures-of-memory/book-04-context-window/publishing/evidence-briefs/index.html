The Octopus Test: Form Does Not Imply Meaning (Bender & Koller 2020)
Language models trained purely on linguistic form (text surface strings) cannot learn meaning (the relation between linguistic expressions and the communicative intent regarding the external world).		 HIGH octopus-test, linguistic-form, meaning, nlu-limits HTML PDF
In-Context Few-Shot Learning via Foundation Scale (Brown et al. 2020)
Scaling autoregressive language models to 175B parameters enables in-context learning without gradient updates, highlighting the fundamental divide of in-context learning vs parametric memory where models execute novel tasks conditioned purely on context window demonstrations.		 HIGH in-context-learning, few-shot, gpt-3, emergent-capabilities, parametric-memory, in-context-learning-vs-parametric-memory HTML PDF
IO-Aware Tiling and Exact Memory-Efficient Attention (Dao et al. 2022)
FlashAttention computes exact self-attention with O(N) memory complexity and 2–4× wall-clock speedup by leveraging GPU SRAM tiling, overcoming the KV cache memory bottleneck and unlocking the long context window for foundation models.		 HIGH flashattention, memory-efficient, gpu-tiling, exact-attention, kv-cache-bottleneck, long-context-window, attention-scaling HTML PDF

Taxonomy and Structural Mechanisms of Hallucination in NLG (Ji et al. 2023)
Hallucination in neural language generation stems from parametric memory corruption, training data bias, and decoding divergence, categorizable into intrinsic and extrinsic factual inaccuracies.		 HIGH hallucination, parametric-memory, factual-grounding, nlg-survey HTML PDF
Empirical Scaling Laws for Neural Language Models (Kaplan et al. 2020)
Language model cross-entropy loss scales as a power-law with compute, dataset size, and parameter count across more than seven orders of magnitude, with architectural hyperparameters having minimal effect.		 HIGH scaling-laws, power-law, compute-optimal, transformer-scaling HTML PDF
Dense Passage Retrieval via Dual-Encoder Vector Representations (Karpukhin et al. 2020)
Dense dual-encoder embeddings trained with in-batch negatives outperform traditional sparse lexical BM25 systems by 9–19% absolute top-20 passage retrieval accuracy in open-domain question answering.		 HIGH dpr, dense-retrieval, dual-encoder, vector-search HTML PDF
Retrieval-Augmented Generation for Parametric and Non-Parametric Memory Synthesis (Lewis et al. 2020)
Combining pre-trained parametric sequence-to-sequence models with non-parametric dense vector index retrieval resolves the RAG vs fine-tuning trade-off, reducing factual hallucination without expanding parametric memory.		 HIGH rag, rag-vs-fine-tuning, non-parametric-memory, dense-retrieval, parametric-memory, long-context-window, seq2seq HTML PDF
U-Shaped Positional Retrieval Degradation in Long Context Windows (Liu et al. 2024)
Language models exhibit a pronounced U-shaped accuracy curve on multi-document question answering and key-value retrieval, performing highest when relevant information appears at the very beginning or end of the input context and degrading significantly when placed in the middle.		 HIGH context-window, lost-in-the-middle, rag HTML PDF

HIGH alibi, length-extrapolation, positional-encoding, context-window HTML PDF
